# StarsVSBlackHoles

StarsVSBlackHoles is a real-time 2D shooter game developed entirely in Python using Pygame.

The player controls an invincible star-like ball that moves across the screen and shoot projectiles toward the mouse cursor. 
Enemy black holes can be destroyed either by projectiles or through direct collision with the player.

## Academic Context

This game was independently designed by Cristian-Eugen Zamfirescu as a second-year university project at the Faculty of Automatic Control and Computers, POLITEHNICA Bucharest.
The project received the highest possible grade.

## Features

- Real-time 2D player movement
- Mouse-controlled aiming and shooting
- Continuously generated enemies
- Projectile-enemy collision detection
- Player-enemy collision detection
- Score tracking
- Sound effects
- Object-oriented game structures
- Continuous game loop running at 60 FPS

## Technologies

- Python 3.12
- Pygame 2.6.1
- Object-oriented programming
- Collision detection
- Event handling
- Vector-based projectile movement

## Installation

1. Install Python 3.12.
2. Clone this repository:

```bash
git clone https://github.com/CristianZ999/StarsVSBlackHoles.git
cd StarsVSBlackHoles
```
3. Install the required dependency:

```bash
python -m pip install -r requirements.txt
```

4. Start the game:

```bash
python StarsVSBlackHoles.py
```
## Controls
- Arrow keys: Move the player
- Mouse cursor: Aim
- Left mouse button: Fire
- Close the game window to exit

## Gameplay

Enemy black holes enter the screen from the right side and move to the left. 
The player is invincible and earns points by shooting enemy black holes or colliding directly with them.
