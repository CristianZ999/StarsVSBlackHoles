# StarsVSBlackHoles

StarsVSBlackHoles is a 2D shooter game developed entirely in Python using Pygame.

The player controls an invincible star-like ball that can move across the screen and shoot projectiles toward the mouse cursor. 
Enemy black holes can be destroyed either by projectiles or through direct collision with the player.

## Academic Context

This game was developed independently by Cristian-Eugen Zamfirescu as a second-year university project at the Faculty of Automatic Control and Computers, POLITEHNICA Bucharest..
The project received the highest possible grade.

## Features

- Real-time 2D player movement
- Mouse-controlled shooting direction
- Continuously generated enemies
- Projectile-enemy collision detection
- Player-enemy collision detection
- Score tracking
- Sound effects
- Object-oriented game structures
- Continuous game loop running at 60 FPS

## Technologies

- Python 3.12
- Pygame
- Object-oriented programming
- Collision detection
- Event handling
- Vector-based projectile movement

## Instalation

1. Install Python 3.12.
2. Download or clone this repository
3. Open a terminal inside the project folder
4. Install the required dependency: ```bash python -m pip install - requirements.txt
5. Start the game: python StarsVSBlackHoles.py

## Controls
- Arrow keys: Move the player
- Mouse cursor: Aim
- Left mouse button: Fire
- Close the game windows to exit the game

## Gameplay

Enemy black holes enter the screen from the right side and move to the left. 
The player is invincible and earns point by shooting enemy black holes or colliding directly with said enemies.
